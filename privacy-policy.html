WinDel Undo 隐私政策

更新日期：2026 年 11 月 23 日 ｜ 适用版本：1.0.0.0 及以上 ｜ 开发者/发布者：不正常赛博捅讯社

一句话版本：WinDel Undo 不收集、不上传、不传输任何用户数据；应用不含任何网络通信功能，所有处理均在本机完成。

一、我们收集什么

本应用不收集、不上传、不传输任何用户数据。应用不含网络通信功能，没有遥测、没有统计 SDK、没有广告组件，也不会在后台与任何服务器交换数据。

二、本地处理的数据

  • 应用在扫描时读取本机存储介质的元数据（目录树、NTFS 主文件表记录、卷影副本），全部在内存中处理；
  • 扫描结果中的文件名与路径仅在应用界面内显示，不会写入任何文件、不会外发；
  • 应用不读取浏览器历史、通讯录、照片库等与恢复功能无关的数据。

三、磁盘写入

唯一对磁盘的写入是「恢复」功能：将用户明确选中的内容复制回其原始路径。

  • 应用不会修改、删除或移动任何现有文件；
  • 目标位置已存在同名文件时一律跳过，绝不覆盖；
  • 恢复路径经过安全校验，拒绝任何越界路径。

四、权限说明

应用需要管理员权限，用于读取卷影副本（VSS）与 NTFS 主文件表（$MFT）。权限提升由用户主动触发（UAC 确认），应用不做任何静默提权。

五、第三方组件

本应用基于 Tauri 框架与 Microsoft Edge WebView2 运行库开发。本应用未接入任何第三方分析、统计或广告 SDK。

六、卸载

卸载方式：Windows 设置 → 应用 → 已安装的应用 → WinDel Undo → 卸载。卸载即完全移除，本应用不残留常驻后台进程或自启动项。

English Summary

WinDel Undo is a read-only Windows file-recovery tool. It collects, uploads, and transmits no user data and contains no networking capability — no telemetry, analytics, or ads. All processing happens locally. The only disk write is the explicit "Restore" action, which copies user-selected items back to their original paths and never overwrites existing files. Administrator rights are requested (via UAC, user-initiated) solely to read volume shadow copies and the NTFS Master File Table. Contact: dan_bl@163.com.
